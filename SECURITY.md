# Security policy

ASTROLENZA v19 is a static, local research prototype. It is not designed, assessed or approved as a safety-critical or medical system.

## Reporting a concern

Do not publish exploit details, credentials, tokens, private telemetry or personal/medical information in a public issue. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately and request a secure reporting route.

## Sensitive data

Never commit API keys, access tokens, passwords, private keys, `.env` files, personally identifiable information, real crew/medical records, confidential mission operations, hardware telemetry or unreleased research data. Verify licensing and redistribution rights for all media.

Security reports are triaged as prototype-software issues. A fix or test result is not certification for flight, EVA, clinical or other operational use.
